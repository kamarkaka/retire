## Container omissions

- `people`: Required A object, optional B object, and required household domicile.
- `market`: Optional documented algorithm defaults; US series use historical rows directly.
- `one_time`: Optional empty list.
- `properties`: Optional empty list.
- `accounts`: Fixed three in withdraw order: brokerage, after_tax, pre_tax; property proceeds reference validation still applies.

## Automated verification

`npm run check` checks strict parsing, portable round trips, builder workflows, independent numerical cases, and the current inventory. No manual sign-off is required. Detailed evidence is in [implementation status](implementation-status.md). Everyone stays alive through the younger person’s Max age year (or the person’s, when alone); sex is descriptive. The household has one domicile country and one or two people. Social Security is excluded: no benefits are ever paid. Budget is the single aggregate medical base; care is always additional through the final horizon and has no end age/scope. CNY cash interest is intentionally omitted and may return in a future model.
